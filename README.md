# Fuja das P2

Provas antigas de P2 do ciclo básico da Poli, transcritas e resolvidas questão por questão.
Uma iniciativa da chapa Prisma · Grêmio Politécnico.

Site: https://chapaprisma.github.io/fuja-das-p2/

- `index.html` — página inicial
- `<matéria>/index.html` — Raio-X ou lista de provas da matéria
- `<matéria>/pdf/` — versão para treinar (`_enunciado.pdf`) e resolução (`_resolucao.pdf`)

As resoluções estão em revisão. Achou um erro? Fale com @prisma.poli.
